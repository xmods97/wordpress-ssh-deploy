# FIRST RUN — EXISTING CODEX PROJECT

Отправь это сообщение в новой сессии Codex после копирования файлов:

```text
В уже существующий проект внедрена система Codex Primary + Claude Secondary.

Codex остаётся главным агентом проекта и всех текущих незавершённых задач.
Claude подключается только как второй агент и ревьюер.
Окончание лимита Codex не передаёт управление Claude.

Прочитай AGENTS.md и файлы .ai.

Пока не изменяй рабочий код.

Синхронизируй .ai/STATE.md с фактическим состоянием:
- PROJECT_ID;
- текущий TASK_ID и название;
- DOMAIN;
- ветка и worktree;
- BASE_COMMIT и LAST_SYNC_COMMIT;
- git status;
- изменённые файлы;
- выполненные проверки;
- scope;
- риски;
- следующий шаг.

Обязательно сохрани:
- PROJECT_LEAD: CODEX;
- TASK_LEAD: CODEX;
- REVIEWER: CLAUDE;
- WORK_LOCK: CODEX.

После синхронизации кратко сообщи роли, TASK_ID, ветку, commit и найденные противоречия.
```

Первое сообщение Claude Code:

```text
Ты подключаешься к уже существующему проекту, которым руководит Codex.

Codex остаётся PROJECT_LEAD и TASK_LEAD текущих задач.
Твоя роль — второй агент, консультант и read-only reviewer.
WORK_LOCK остаётся у Codex.

Прочитай CLAUDE.md и файлы .ai, проверь роли и состояние Git.
Ничего не изменяй.
Кратко сообщи, что уже сделано, какой следующий шаг и где ты можешь быть полезен как ревьюер.
```

## Проверка маршрутизации

После первичного изучения проекта каждый агент должен кратко указать:

- какие задачи лучше оставить Codex;
- какие задачи разумно поручить Claude Code;
- где достаточно консультации или независимого review;
- какие задачи можно решить в обычном чате;
- почему.

Это только рекомендации. Они не меняют роли и не запускают передачу автоматически.
