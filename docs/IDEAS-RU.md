# Идеи развития

Идеи из этого файла не считаются согласованными этапами реализации. Перед
переносом идеи в основной план необходимо отдельно определить границы,
безопасность и критерии приёмки.

## I-001. Удалённый сервер разработки

**Статус:** идея

Использовать отдельный виртуальный сервер как постоянное рабочее окружение:

- разрабатывать сайты на закрытых dev-поддоменах;
- выделять каждому сайту отдельные каталог, базу и системного пользователя;
- запускать Codex CLI от непривилегированного пользователя;
- получать production-БД и uploads только в направлении сервера разработки;
- отправлять на production только проверенный код;
- синхронизировать основной компьютер через Git и безопасный pull данных;
- закрывать dev-сайты авторизацией или VPN и запрещать индексацию;
- отключать платежи, письма, webhooks и другие реальные интеграции.

Среда разработки должна быть отделена от production. Доступ к production
выдаётся ограниченному deploy-пользователю без права штатной записи БД.

Логически идея относится к этапу 12 «Работа с нескольких компьютеров».
